# Сайт психолога Надежды Боярсковой

Статичный сайт: HTML + CSS + JS, без сборки. Подходит для GitHub Pages.

## Что заменить перед публикацией
1. `privacy.html` — дата редакции 19.10.2026; при изменении текста обновите дату.
2. Фото в `assets/img/` — оригиналы (hero.jpg — с вырезанным фоном на красном). `og-image.jpg` — превью ссылки в мессенджерах и соцсетях; при смене фото пересоберите его.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в него **содержимое** этой папки (index.html должен лежать в корне).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Settings → Pages → Custom domain: впишите `psycholognado.ru` (файл CNAME уже есть) и включите «Enforce HTTPS».
4. У регистратора домена добавьте DNS-записи:
   - для корневого домена — четыре A-записи: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153;
   - для `www` — CNAME на `ВАШ-ЛОГИН.github.io`.

## Как сайт адаптируется
- Мобильный: до 767 px · Планшет: 768–1099 px · Десктоп: от 1100 px.
- Сетка: 4 / 8 / 12 колонок, контейнер 1200 px.
- `main.js` ставит на `<html>` классы `is-mobile` / `is-tablet` / `is-desktop` и `is-touch` — их можно использовать в стилях.
